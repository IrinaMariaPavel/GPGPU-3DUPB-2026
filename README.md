### GPGPU Workshop - 3DUPB
*Mihnea Mitrache, mihnea.mitrache@upb.ro*

In this repository you will find the code for the GPGPU Workshop held at 3DUPB, Faculty of Automatic Control and Computer Science, University Politehnica of Bucharest.

#### Requirements
In order to run CUDA kernels, you need access to a CUDA capable environment. You can either use a local machine with a CUDA capable GPU or use our cluster.

#### Guides
1. If you have an NVIDIA GPU and want to work on your local machine, you can find the guide [here.](./Local/)
2. Otherwise, you can use our cluster. You can find the guide for accessing the cluster [here.](./Cluster/)
